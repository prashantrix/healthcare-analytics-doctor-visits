# Healthcare Analytics for Doctor Visits

## Project Overview
This project explores healthcare data to understand patterns in doctor visits and examine how patient characteristics and illness levels relate to healthcare utilization.

## Objectives
- Analyze doctor visit frequency.
- Explore patient demographics such as age and gender.
- Examine the relationship between illness level and doctor visits.
- Create visualizations to communicate findings.
- Practice exploratory data analysis using Python.

## Dataset
The dataset contains 5,190 records and 13 columns.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Workflow
1. Load the healthcare dataset.
2. Inspect the dataset and check data quality.
3. Perform exploratory data analysis.
4. Analyze doctor visit patterns.
5. Visualize important relationships.
6. Summarize findings and conclusions.

## Key Findings
- 4,141 records reported zero doctor visits.
- 1,049 records reported at least one doctor visit.
- Female records had a higher average number of visits than male records.
- Average doctor visits generally increased with illness level in this dataset.

## How to Run
1. Clone or download this repository.
2. Install the required libraries.
3. Open the notebook in Jupyter Notebook or Google Colab.
4. Ensure the CSV file is in the expected location.
5. Run the notebook cells in order.

Install dependencies:

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

## Limitations
This project focuses on exploratory analysis. Observed associations do not establish causation, and findings may not generalize beyond this dataset.
